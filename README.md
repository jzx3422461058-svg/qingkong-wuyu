# 晴空物语

仅供个人使用的原生 Mac 学习与生活管理应用。界面采用本地奇幻二次元天空、校园少女头像、系统毛玻璃材质及固定圆形模块入口；无账号、无服务器、无云同步。

## 使用

已安装到 `/Users/junk/Applications/晴空物语.app`，工作台文件夹内也有快捷入口。双击“晴空物语.app”。关闭主窗口后，应用继续在菜单栏运行；菜单栏的云朵图标可重新打开主窗口。Command+Q 为完全退出。

首次使用建议依次进行：

1. 在课程表的“学期”菜单设置第一教学周的周一、教学周数、节次时间与教学时区。初始节次只是模板，请按学校实际作息修改。
2. 添加课程，或把课表截图发给助手整理为 CSV 后，通过“导入课表”预览、校对、确认。
3. 建立训练方案与日期安排，训练结束后逐组记录实际完成结果。
4. 建立长期目标、阶段完成标准与具体行动。
5. 记录个人活动的报名、准备事项及参与结果。
6. 在数据与设置里选择主题、开启通知，按需启用登录后启动，并导出一份备份。

正式空间初始为空。测试记录仅存在独立 QA 目录，不会进入正式数据。

## 数据与恢复

- 正式数据（沿用原应用位置，更名不迁移或清空）：`~/Library/Application Support/Qingyu/workspace.json`
- 本地备份：同目录下的 `Backups/`
- 存储格式：版本化快照，带 SHA-256 完整性校验；临时文件同步落盘后原子替换。
- 有效操作自动保存；表单在停止输入约 0.75 秒后保存草稿。关闭编辑表单保留草稿，“丢弃草稿”清除当前草稿。
- Command+S 保存当前编辑内容；验证不通过时显示具体错误，不提交无效记录。
- 自动备份每天一份，保留最近 7 份。手动备份和重要操作前的恢复点单独保留。
- “导入恢复”会预览备份内容，确认后先保留当前快照，再替换数据。不能读取的数据不会被自动清空。
- 删除的主要记录可在回收站恢复。恢复旧课程若与当前学期规则不兼容，会提示错误，原记录仍保留在回收站。
- 同机备份不能抵御整台电脑或硬盘丢失，可将导出的 `.campusbackup` 文件自行复制到外部存储。

## 课程表导入格式

使用 UTF-8 CSV，表头如下（应用内可导出模板）：

```csv
课程,地点,星期,开始节次,结束节次,周次,单双周
示例课程,北楼203,1,1,2,1-16,每周
双周示例,南楼102,4,5,6,1-16,双周
```

- 星期为 1—7，对应周一至周日。
- 周次可写 `1-16` 或 `"1,3,5"`，单双周可写“每周／单周／双周”。
- 单双周以当前学期教学周计算。
- 一门课有多个时段时写多行。
- 导入前可修改预览；默认跳过相同安排，也可选择保留两份或更新地点。
- “替换当前学期”只替换当前课表并先建立恢复点；历史学期保留。
- 单次停课、调课在周视图点击课程进行；在全部课程列表可恢复原安排。

截图识别由对话中的助手协助完成；App 自身不内置 OCR，也不会上传截图或个人记录。

## 提醒

提醒在主程序后台每 20 秒检查一次，使用当前记录生成，修改和删除后旧安排自动失效。关闭窗口不影响后台检查，完全退出、关机或未登录系统时不会执行。

需要在 macOS 系统设置 → 通知 → 晴空物语中允许通知。若系统权限关闭，应用会显示状态；不影响记录与保存。活动的报名提醒与开始提醒分别设置。错过的近一天提醒会汇总提示，避免睡眠后大量弹出。

## 开发与验证

要求 Apple Silicon Mac、macOS 14+；本次实际构建验证环境为 macOS 26.3.1、Swift 6.3.2 Command Line Tools。旧版 macOS 未实机验证。

```sh
swift run CampusChecks
swift build --product Campus
zsh scripts/package.sh release
```

测试使用可执行断言套件，任意断言失败返回非零退出码。本机没有完整 Xcode/XCTest，测试不依赖它。源码分为纯业务模块 `CampusCore` 和桌面界面模块 `CampusApp`。

安装包输出：`dist/晴空物语.app`，使用本机 ad-hoc 签名，面向当前用户的本机使用，未做公开分发公证。

测试记录见 `docs/TEST_REPORT.md`。视觉素材许可见 `Sources/CampusApp/Resources/Assets.md`。

## 验证边界

- 未实际重启或关机用户电脑；已使用应用退出重开、独立进程回读及磁盘故障模拟测试持久化。
- 系统通知、登录后启动需用户系统授权；以测试报告中的实际状态为准。
- 用户真实课表截图尚未提供，真实课表识别与逐项核对待提供后执行。
- 动效手感仍需本人实际使用验收；主线程回调测量不是 GPU 帧率证明。
