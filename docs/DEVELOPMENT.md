# 开发与验证记录

按模块顺序开发；每一模块完成后先编译、执行针对性测试、定位修复，再进入下一模块。

1. 本地数据底座：原子写入、校验、备份、恢复、失败保留原数据。
2. 课程表：单双周、例外、CSV 导入、周视图与编辑。
3. 健身：方案、安排、逐组实际记录、历史。
4. 长期计划：三层关系、进度、状态、行动。
5. 活动：报名、准备、参与、历史。
6. 数据与设置：保存、备份恢复、偏好、后台通知。
7. 首页整合：真实数据聚合、圆形入口、视觉与动效。

技术方案：SwiftUI + AppKit 原生 macOS；Swift Package Manager；无第三方运行依赖。本地数据通过带 SHA-256 校验的版本化快照原子落盘。应用名暂定“晴屿”，不影响数据标识。

未获得用户真实课表，真实截图导入验收待用户提供；开发使用明确标注的测试数据，正式工作空间不预置假记录。
